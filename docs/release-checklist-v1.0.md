# Release checklist v1.0

Använd denna innan labben används i kursen.

## Repo

- [ ] README är uppdaterad.
- [ ] Alla docs-mallar finns.
- [ ] Alla agent-prompts finns.
- [ ] GitHub Actions kör utan fel.
- [ ] Demoappen och testerna fungerar.
- [ ] Scripts är körbara.

## GitHub-konfiguration

- [ ] Labels finns.
- [ ] Milestones finns.
- [ ] Project-vyer är skapade.
- [ ] Branch protection är aktiv på `main`.
- [ ] PR-template finns.
- [ ] CODEOWNERS är satt enligt kursens ägarstruktur.

## Pedagogik

- [ ] Lärarinstruktioner är genomgångna.
- [ ] Bedömningsmatris är förankrad.
- [ ] AI-policy är tydlig.
- [ ] Säkerhetsavgränsning är tydlig för studenterna.
- [ ] Simulerade alerts är förberedda.
