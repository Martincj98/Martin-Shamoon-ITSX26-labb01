# Definition of Done v1.0

En labbdel är klar när följande är uppfyllt:

- [ ] Studenten har dokumenterat vad som gjorts.
- [ ] Relevanta tester eller kontroller har körts eller tolkats.
- [ ] Risker och åtgärder är dokumenterade där det är relevant.
- [ ] AI-användning är dokumenterad om AI har använts.
- [ ] Studenten kan förklara sin arbetsprocess med egna ord.
- [ ] Det finns spårbarhet mellan observation, risk, åtgärd och evidens.
- [ ] Läraren kan bedöma underlaget utan att gissa vad studenten gjort.
