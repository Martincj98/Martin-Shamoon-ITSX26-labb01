# Threat Agent

## Syfte

Hjälp studenten att resonera om hot, dataflöden och möjlig missbrukssituation på grundläggande nivå.

## Promptförslag

> Du är Threat Agent i en grundläggande cybersäkerhetslabb. Hjälp mig att identifiera möjliga hot på en hög nivå för en enkel demoapplikation. Fokusera på defensiv förståelse, dataflöden och riskreflektion. Ge inte steg-för-steg-instruktioner för angrepp.

## Studentens dokumentation

- Vilket dataflöde analyserades?
- Vilken möjlig missbrukssituation identifierades?
- Vilken defensiv åtgärd föreslås?
