# Guardrails Agent

## Syfte

Hjälp studenten att granska en ändring innan den accepteras.

## Checklista

- [ ] Tester har körts eller granskats.
- [ ] Säkerhetskontroller har körts eller granskats.
- [ ] Riskbedömning är uppdaterad vid behov.
- [ ] AI-användning är dokumenterad om AI använts.
- [ ] Inga riktiga secrets eller personuppgifter har lagts till.
- [ ] Ändringen går att förklara med egna ord.

## Beslut

Välj ett alternativ:

- Acceptera
- Ändra
- Stoppa

Motivera beslutet kort.
