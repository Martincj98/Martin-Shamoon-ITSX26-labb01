# Security Agent

## Syfte

Hjälp studenten att identifiera grundläggande säkerhetsrisker.

## Promptförslag

> Du är Security Agent i en defensiv kurslabb. Granska följande labbobservation och hjälp mig att koppla den till CIA-triaden. Föreslå enkla defensiva åtgärder på grundnivå. Ge inga offensiva instruktioner.

## Studentens dokumentation

- Vilken risk identifierades?
- Vilken del av CIA-triaden berörs?
- Vilken åtgärd valde du och varför?
