# Version v1.0

Detta paket kompletterar labb-repot med GitHub-konfiguration:

- labels,
- milestones,
- Projects-fält och vyer,
- branch protection-rekommendation,
- pull request-template,
- CODEOWNERS-mall,
- auto-triage workflow,
- issue templates,
- Copilot/agent-policy,
- Definition of Done,
- release checklist,
- GitHub CLI-exempel.

Paketet ändrar inte ditt GitHub-repo automatiskt. Det är ett konfigurationsunderlag som kopieras in i repot och aktiveras via GitHub UI eller GitHub CLI.
